# Personal Profile Web Application

## Project Description
This project is a simple Personal Profile Web Application developed using HTML, Java Servlet and JSP. It allows users to enter their personal information through an HTML form and displays the submitted information on a JSP page.

## Technologies Used
## Technologies Used
- HTML
- CSS
- Java
- Java Servlet
- JavaServer Pages (JSP)
- GlassFish Server 4.1.1
- NetBeans IDE

## Features
- Personal information form.
- Submit information using HTTP POST.
- Process form data using Java Servlet.
- Display submitted information using JSP.
- Simple CSS styling.

## How to Run the Application

1. Install NetBeans IDE and configure GlassFish Server 4.1.1.
2. Download or clone this repository.
3. Open the project in NetBeans IDE.
4. Make sure GlassFish Server 4.1.1 is configured as the project server.
5. Right-click the project and select Run.
6. Open the application in your web browser.
7. Fill in the personal information form and click Submit Profile.
8. The submitted information will be displayed on the profile page.
